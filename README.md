# SSTM Bot v3

بوت منظم: كل أمر في ملف مستقل داخل `src/commands`، ويعمل بـ `config.json`.

## التحديثات الأخيرة

- ✅ حذف كل أوامر `tool*` بالكامل.
- ✅ إضافة الأوامر الظاهرة في الصور (أسماء الأوامر كما هي).
- ✅ الحفاظ على أوامر الأساس: `help`, `bots`, `status`, `line`, `addowner`, `say`, `come`, `khat`.
- ✅ الأمر `خط` (alias لـ `khat`) يمسح الرسالة ويرسل الخط المحفوظ.

## التشغيل

```bash
npm install
npm run check
npm run register
npm start
```
